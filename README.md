# daystack Phone

An Android dialer with an iOS-style look, Samsung One UI reachability and Google Material You colors.

Part of **daystack apps**, a suite of privacy-friendly Android apps (Phone, Messages, Contacts, Notes, Gallery, Files, Calendar) that share one design system.

> **Status:** planning. This repo holds the design and plan docs only. No app code yet.

## What it will be

- Bottom tab bar: Favorites · Recents · Contacts · Keypad
- Round iOS-style keypad
- Swipe a contact right to call, left to message (Samsung style)
- Tall One UI header that keeps content in thumb reach
- Accent color from your wallpaper (Material You)
- Rounded, filled icons and the Inter typeface
- No ads, no trackers, no internet permission
